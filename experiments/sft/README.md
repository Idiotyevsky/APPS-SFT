# SFT experiment outputs

Large, ignored local artifacts are kept here instead of beside the SFT source
and configuration files:

experiments/sft/outputs/   checkpoints, probes, reports
experiments/sft/exports/   historical merged exports
experiments/sft/logs/      training/evaluation logs

The legacy paths sft/outputs, sft/exports, and sft/logs are local
compatibility symlinks. These artifacts are intentionally not committed.
